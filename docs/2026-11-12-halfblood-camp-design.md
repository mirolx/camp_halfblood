# Camp Half-Blood 시뮬레이션 — 설계서 / Design

작성일: 2026-11-12
상태: 승인 대기

---

## 1. 의도 (Why)

퍼시 잭슨 시리즈의 팬이 "내가 캠프 하프블러드에 들어간다면?"을 직접 체험해보는 개인 팬 프로젝트.
게임이 아니라 **영화처럼 지켜보는 시뮬레이션**이다. 핵심 감정은 "이입" — 원작을 읽으며 상상했던
캠프의 하루를, 내 캐빈에서 눈을 뜨는 순간부터 캠프파이어까지 보고 듣는 것.

두 단계로 구성된다.
1. **캐빈 테스트** — 질문에 답하고, 신에게 "인정(claiming)"받는다.
2. **하루 시뮬레이션** — 소속 캐빈에서 아침을 맞고, 캠프의 하루가 약 10분 동안 흘러간다.

## 2. 목표 / 비목표 / 안티목표

**목표**
- 원작 설정에 충실한 캐빈 배정 (아래 4절)
- 그리스·로마 신화 느낌의 판타지 분위기: 대리석, 금빛 햇살, 신화 속 생물
- 사실적인 소리 — 이 프로젝트의 몰입감은 소리가 절반이다
- 위에서 내려다보는 시점 ↔ 1인칭 시점 전환
- 한국어 / English 언어 토글

**비목표 (안 하는 것)**
- 게임 요소: 점수, 퀘스트, 전투 조작, 인벤토리, WASD 이동
- 세세한 디테일 재현 (모든 건물·인물 고증) — 분위기 우선
- 모바일 최적화 (데스크톱 브라우저 기준. 모바일에서 깨지지만 않으면 됨)
- 마이너 신 캐빈 (헤카테, 히프노스 등), 하데스 캐빈

**안티목표 (이렇게 되면 실패)**
- 소리가 없거나 "삑삑" 하는 합성음처럼 들림
- HUD·버튼이 화면을 덮어서 영화가 아니라 게임 UI처럼 보임
- 유치하거나 장난감 같은 비주얼 (단순화된 3D여도 조명·안개·물 반사로 분위기를 낸다)
- 원작 설정을 깨는 것 (예: 헤라의 자녀로 배정)
- 영화/드라마 공식 아트, 로고, 노래 가사를 그대로 가져다 쓰는 것

## 3. 제약

- 브라우저에서 로컬로 실행되는 3D 웹 페이지 (정적 파일, 서버 불필요 또는 개발 서버 정도)
- 3D 비주얼은 코드로 생성. Higgsfield 3D 카탈로그를 시험했으나 (docs/tests/pegasus_test.png) 모델이 단순 로우폴리 일반 소품뿐이고 그리스 건축물이 없어 품질 향상이 없음 → 사용하지 않음
- 소리는 **무료 실제 녹음 효과음** (Pixabay 등) + **음악은 Suno** (사용자가 생성, 비상업 개인 용도). 현재 연결된 Higgsfield에는 오디오 생성 기능이 없음
- 음원 다운로드는 파일마다 이름·출처를 사용자에게 보여주고 확인받은 뒤 받는다
- 일반 노트북에서 부드럽게 (목표 60fps, 최소 30fps)
- 브라우저 자동재생 정책 때문에 소리는 사용자 클릭 이후 시작

## 4. 캐빈 테스트

### 결과 후보 (올림포스 12신 중 원작 설정 반영)

| 캐빈 | 신 | 성향 키워드 | 상징 (claiming) |
|---|---|---|---|
| 1 | Zeus | 리더십, 야망, 정의감, 자존심 | 번개 |
| 3 | Poseidon | 의리, 자유로움, 감정적, 반항기 | 삼지창 |
| 4 | Demeter | 돌봄, 인내, 자연, 꾸준함 | 밀 이삭 |
| 5 | Ares | 경쟁심, 용기, 직설적 | 불타는 창 / 멧돼지 |
| 6 | Athena | 전략, 지혜, 호기심, 계획 | 부엉이 |
| 7 | Apollo | 예술, 음악, 치유, 낙천 | 태양 / 리라 |
| 8 | Artemis → **사냥꾼 합류** | 독립, 자연, 사냥, 자매애 | 은빛 활과 초승달 |
| 9 | Hephaestus | 손재주, 발명, 내향적 몰입 | 망치와 모루 |
| 10 | Aphrodite | 공감, 매력, 미적 감각 | 비둘기 / 장미 |
| 11 | Hermes | 재치, 장난기, 적응력, 여행 | 날개 달린 지팡이 (카두케우스) |
| 12 | Dionysus | 자유분방, 축제, 낙관 | 포도덩굴 / 술잔 |

- **헤라(2번)**: 결과에서 제외 (원작: 자녀 없는 명예 캐빈)
- **아르테미스(8번)**: 결과로 나오면 "아르테미스의 사냥꾼으로 합류"로 연출. 사냥꾼들은 캠프 방문 시 8번 캐빈에 머무르므로 시뮬레이션은 8번 캐빈에서 시작

### 시작 화면 — 성별 선택
- 테스트 전에 남자 / 여자 중 하나를 고른다 (외형 커스터마이징은 없음)
- 선택에 따라 "나" 캐릭터의 실루엣이 달라진다: 체형, 머리 모양(예: 짧은 머리 / 긴 머리를 묶은 포니테일). 옷은 둘 다 주황색 캠프 티셔츠
- 이 차이는 claiming 장면의 뒷모습, 오버뷰 시점에서 보이는 "나", 1인칭 시점의 그림자 등에서 드러난다
- 원작상 아르테미스의 사냥꾼은 소녀만 될 수 있으므로, **남자를 고르면 결과 후보에서 아르테미스를 제외**한다 — *설계자 판단*

### 테스트 구조
- 질문 약 12개, 각 4지선다. 성격·가치관·상황 판단 질문 (예: "퀘스트에 동료 한 명만 데려갈 수 있다면?")
- 각 선택지는 1~3명의 신에게 가중치 점수를 준다. 모든 신이 대략 비슷한 빈도로 나올 수 있게 균형을 맞춘다
- 동점이면 마지막 몇 문항의 비중을 높여서 결정 (빌더 재량)
- 진행 표시는 얇은 바 하나 정도, 배경은 은은한 캠프 분위기

### 결과 연출 — "인정의 순간"
밤의 캠프파이어 앞, 내 머리 위에 신의 상징이 빛나며 떠오른다 (원작의 claiming 장면).
신 이름, 캐빈 번호, 짧은 설명이 뜨고 → "캠프로 들어가기" 버튼 → 시뮬레이션 시작.
아르테미스는 은빛 달빛 연출 + "사냥꾼에 합류했다" 문구.

## 5. 하루 시뮬레이션

### 비주얼 방향
- 스타일라이즈드 3D (부드러운 로우폴리), 따뜻한 색감. 참고 무드: 대리석 아치 너머 호수, 페가수스, 주황색 캠프 티셔츠의 캠퍼들
- 분위기는 조명으로: 시간대별 하늘색·태양 각도, 아침 안개, 물 반사, 해 질 녘 황금빛, 밤의 별과 모닥불 빛

### 캠프 배치 (원작 기반, 단순화)
- 캐빈 12채 U자(Ω) 배치. 각 캐빈은 신에 맞는 외관 (포세이돈=바다빛 돌, 아테나=부엉이 장식 회색, 헤르메스=낡은 갈색 등)
- 빅 하우스 (파란 4층 농가), 식당 파빌리온 (대리석 기둥, 지붕 없음, 바다/호수 전망)
- 카누 호수, 숲, 딸기밭, 언덕 위 소나무 (탈리아의 나무 + 황금 양털)
- 활쏘기장, 검술 아레나, 페가수스 마구간, 캠프파이어 원형극장

### 캐빈별 디자인 (원작 묘사 기반)

각 캐빈은 멀리서 봐도 어느 신의 캐빈인지 알아볼 수 있을 만큼 개성 있게. 결과로 배정된 캐빈은 **내부까지** 만든다 (시뮬레이션이 그 안에서 시작하므로).

| 캐빈 | 외관 | 내부 (시작 장면용) | 소리·분위기 |
|---|---|---|---|
| 1 Zeus | 흰 대리석, 굵은 기둥, 번개 문양 청동 문. 웅장하고 차가움 | 텅 빈 높은 천장, 거대한 제우스 석상 | 멀리서 우르릉 천둥 |
| 2 Hera | 우아한 흰 건물, 공작 깃털 장식 | (결과 아님, 외관만) | — |
| 3 Poseidon | 낮고 긴 회색 바다 돌 건물, 조개·산호가 박힌 벽 | 바닷빛 조명, 벽의 분수, 조개 장식 | 파도 소리, 짠 바람 |
| 4 Demeter | 잔디 지붕, 벽을 타고 오르는 토마토 덩굴과 꽃 | 말린 허브, 화분, 나무 침대 | 벌 소리, 바람에 흔들리는 밀 |
| 5 Ares | 벗겨진 빨간 페인트, 지붕의 철조망, 문 위 멧돼지 머리 | 어수선한 무기 거치대, 낡은 침대 | 시끄러운 기합, 금속 소리 |
| 6 Athena | 은회색, 문 위 부엉이 조각 | 책장, 지도·설계도로 가득한 작업대 | 책장 넘기는 소리, 조용함 |
| 7 Apollo | 햇빛에 눈부시게 빛나는 금빛 건물 | 악기들 (리라·기타), 밝고 따뜻한 빛 | 리라 선율 |
| 8 Artemis | 은빛, 달빛에 빛남. 사냥 장식 | 은색 장식, 활과 화살통, 늑대 가죽 | 늑대 울음 멀리, 숲 바람 |
| 9 Hephaestus | 굴뚝 달린 공장 같은 건물, 황동과 톱니바퀴 | 작업대, 기계 부품, 대장간 불빛 | 망치질, 기계 돌아가는 소리 |
| 10 Aphrodite | 분홍빛, 화분 상자, 레이스 커튼 | 거울, 옷장, 꽃 | 은은한 음악, 웃음소리 |
| 11 Hermes | 평범하고 낡은 갈색, 가장 붐빔 | 침낭이 바닥까지 꽉 찬 방 | 시끌벅적, 장난치는 소리 |
| 12 Dionysus | 포도덩굴이 뒤덮은 보라빛 건물 | 덩굴 장식, 포도, 편안한 분위기 | 귀뚜라미, 느긋함 |

(Hestia, Hades 등 마이너 캐빈은 만들지 않음 — 비목표)

### 타임라인 (총 약 10분, 실제 시간)

| 시간 | 장면 | 주요 소리 |
|---|---|---|
| 0:00–1:30 | **새벽·아침** — 내 캐빈 안에서 시작. 소라고둥이 울리고 창밖으로 안개 낀 호수와 숲. 문이 열리며 카메라가 캠프 전경으로 빠져나감 | 소라고둥, 새소리, 잔잔한 물결, 문 삐걱 |
| 1:30–2:30 | **캠프 전경** — 캠퍼들이 캐빈에서 나와 움직이기 시작 | 아침 웅성거림, 발소리, 바람 |
| 2:30–5:00 | **오전 훈련** — 활쏘기장과 검술 아레나 | 활시위·화살 꽂히는 소리, 청동 검 부딪침, 기합 |
| 5:00–6:30 | **페가수스 비행** — 하늘을 나는 페가수스들, 호수 위를 스침 | 날갯짓, 말 울음, 바람 |
| 6:30–8:00 | **저녁 식사 (해 질 녘)** — 식당 파빌리온, 화로에 음식을 바치는 의식 | 식기 소리, 웅성거림, 불 타는 소리 |
| 8:00–10:00 | **캠프파이어 (밤)** — 노래와 함께 불꽃이 커지고 색이 바뀜 (원작: 분위기에 따라 불이 커짐). 별이 뜨며 하루 마무리 | 가사 없는 허밍/새로 만든 노래, 모닥불, 귀뚜라미 |

마지막에는 "다시 보기 / 테스트 다시 하기" 정도의 조용한 엔딩 화면.

### 카메라
- **오버뷰 시점 (기본)**: 장면에 맞춰 자동으로 움직이는 시네마틱 카메라. 사용자가 마우스로 드래그해 둘러볼 수 있고, 손을 떼면 자동 카메라로 부드럽게 복귀
- **1인칭 시점**: 버튼(또는 키) 하나로 전환. 내 캐빈 소속인 "나" 캐릭터의 눈높이에서 하루 일정을 따라감. 마우스로 고개만 돌릴 수 있음 (이동 조작 없음) — *설계자 판단*
- 전환은 부드러운 카메라 이동 (뚝 끊기지 않게)

### UI (최소화)
- 화면 구석에: 시점 전환, 일시정지/재생, 음량·음소거, 언어 토글(한/EN)
- 현재 장면 이름과 시간대가 잠깐 자막처럼 떴다 사라짐 (예: "Morning · 소라고둥이 울린다")
- 일정 시간 마우스 움직임이 없으면 UI가 사라짐

## 6. 소리

- 효과음·환경음은 **무료 실제 녹음 음원**을 받아 `assets/audio/`에 저장. 출처와 라이선스는 `assets/audio/CREDITS.md`에 기록
- 음원 목록: 소라고둥(conch shell horn), 새벽 새소리, 호수 물결, 바람/숲, 캠프 웅성거림, 발소리, 활시위·화살, 검 부딪침, 날갯짓(큰 새/비둘기 날갯짓을 낮게 피치 조정) + 말 울음, 식당 소음, 모닥불, 귀뚜라미·밤 소리, claiming 연출음, 테스트용 잔잔한 배경음
- **음악 (캠프파이어 노래, 테스트 배경음, claiming 연출음악)**: 사용자가 **Suno**에서 직접 생성해 `assets/audio/music/`에 넣는다 (개인·비상업 용도). Claude는 곡별 Suno 프롬프트와 파일 이름을 준비한다
  - 캠프파이어 노래: 어쿠스틱 포크풍 캠프 합창, 기타·손뼉, 모닥불 가에서 여럿이 부르는 느낌. 새 가사 (원작 가사 사용 금지)
  - 테스트 배경음: 잔잔한 고대 그리스풍 리라·하프 앰비언트, 가사 없음
  - claiming 연출: 짧고 신비로운 합창 스팅 (5~10초)
- 원하는 음원을 무료로 구하지 못하면 가장 가까운 소리를 가공(피치·리버브)해서 대체
- 재생: Web Audio로 레이어링. 시간대에 따라 환경음이 크로스페이드. 3D 위치 기반 소리 (검술장에 가까워지면 검 소리가 커짐)
- 원작/영화의 실제 곡이나 가사는 쓰지 않는다

## 7. 언어 (한국어 / English)
